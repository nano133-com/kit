# Nanoterra character for Three.js: the prompt

```
Show the Nanoterra island character in this Three.js game with
@nano133/character. Follow the package's ai/SPEC.md step by step. Make one
character for each player with createCharacter, add its object and its shadow
to the scene, and call update(dt, { speed, airborne, verticalSpeed }) once
each frame with the game's own numbers (dt in seconds). Use HEIGHT and RADIUS
for the collider. Check every look with isLook before it reaches the
character. Ask me where each player's look comes from and which quality
(high or low) to use. Call dispose when a character leaves the game.
```
