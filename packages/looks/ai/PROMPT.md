# Looks: the prompt

```
Check and manage the looks of this game with the npm package @nano133/looks and follow its SPEC
step by step: https://nano133.com/build/cosmetics
Use checkLooks() on looks.json when the game starts, lookProblems() to list every mistake, and
removalProblems() before I change the file: a look that a player owns must stay in the file.
Write the new looks.json with looksJson(). Never put a random look, a loot box or a look that
changes a score. Keep one free look. Do not send prices or sales to any other site.
```
